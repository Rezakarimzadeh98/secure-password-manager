# Code of Conduct

This project aims to be useful, respectful, and safe for contributors.

## Expected behavior

- Be respectful and specific in feedback.
- Assume good intent and discuss the code, not the person.
- Help new contributors understand project constraints.
- Keep security discussions responsible and non-exploitative in public threads.

## Unacceptable behavior

- Harassment, discrimination, or personal attacks
- Repeated disruptive behavior or bad-faith arguments
- Sharing private or exploit details publicly when a responsible disclosure path exists

## Enforcement

Project maintainers may remove comments, close threads, or block participation when behavior makes collaboration unsafe or unproductive.
